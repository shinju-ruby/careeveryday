# 갓생 살자! 生產力小幫手

個人生產力 webapp：月／週／日計畫、待辦（步驟、標籤、倒數）、甘特圖、行程提醒、日記與記帳、靈感筆記。

- 單一 `index.html`，純 HTML/CSS/JavaScript，不需要安裝。
- 資料只存在使用者自己的瀏覽器（localStorage），不會上傳到任何伺服器。可在「設定」匯出／匯入備份。
- 提醒需要網頁保持開啟。
